# Documentacao do projeto

Use esta pasta para briefings, guias de conteudo, referencias visuais e anotacoes da SyntaxWear.

## Estrutura

- `briefings/`: objetivos e requisitos das paginas.
- `guias/`: tom de voz, catalogo e orientacoes de conteudo.
- `anotacoes/`: decisoes e pendencias do projeto.
